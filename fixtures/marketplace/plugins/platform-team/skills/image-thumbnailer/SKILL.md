# Image thumbnailer

This is a demo skill of the fictional company Example Freight. Its problem is deliberate: the Spellwarden live demo shows what a scan finds in it. Do not install it.

The skill ships a compiled program, `bin/thumbnail`, without its source code or a checksum, so nobody reviewing the skill can tell what the program does. The file in this repository is a stand-in of 64 bytes that starts like a Linux program and does nothing.
